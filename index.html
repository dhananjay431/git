RawGit Local

Serve raw files from GitHub, GitLab, Bitbucket, Gitea, and Codeberg with proper MIME types and caching.

Endpoints

Development (short cache)

/dev/{hosting}/user/repo/ref/path

Example: /dev/github/owner/repo/main/file.js

Production / CDN (permanent cache)

/cdn/{hosting}/user/repo/ref/path

Example: /cdn/github/owner/repo/v1.0.0/file.js

Bare GitHub (defaults to GitHub dev cache)

/user/repo/ref/path

Example: /owner/repo/main/file.js

Supported Hostings

  • github
  • gitlab
  • bitbucket
  • gitea
  • codeberg

Running on nginx with proxy caching.
